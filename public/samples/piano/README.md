# Piano samples

Salamander Grand Piano by Alexander Holm, licensed under the Creative Commons
Attribution 3.0 Unported licence (CC BY 3.0),
https://creativecommons.org/licenses/by/3.0/.

These 30 mp3 files (one note every minor third from A0 to C8, a single dynamic
layer) are the reduced set published with the Tone.js examples at
https://tonejs.github.io/audio/salamander/. The app plays the nearest
recording pitch-shifted to each note; see `src/audio/piano.ts`.
